# 佐渡島旅行サイト

## 概要
このサイトは、佐渡島旅行の気分を高めるために制作した架空の旅行LPです。
旅行前に気持ちを盛り上げることを目的に、「海」「落ち着き」「少し特別感のある旅」をテーマとして設計しました。

## 制作目的
LPアーカイブに掲載されていた旅行サイトを参考に、構成を分解したうえで、自分の現在のHTML/CSSのスキルで再現できる形に落とし込みました。
ヒーロー、ナビゲーション、エリア紹介、フッターという流れで構成し、1ページのLPとして成立することを意識しています。

このサイトは「不特定多数のユーザー向け」というより、旅行に行く前の自分の気分を高めることを目的に制作しています。
そのため、自分自身をユーザーとして設定し、「どんな雰囲気なら旅行への期待感が高まるか」を考えながらデザインしました。

## デザイン・設計の意図
旅行先が佐渡島であり、フェリー旅・海鮮・アメジスト拾いなど、海を連想する要素が多かったため、全体の配色は水色・青・白を基調にしました。
また、旅行は喧騒から離れてのんびり過ごす体験だと考えたため、余白を広めに取り、落ち着きのある印象を意識しました。

差し色に黄色を使ったのは、水色や青とのコントラストをつけ、ホバー時の変化を分かりやすくするためです。
視認性だけでなく、旅行前のわくわく感も表現したいと考え、ホバー時に色が変化するデザインを採用しました。

ヒーロータイトルには明朝系フォントを使い、特別感やリゾート感を演出しました。
一方で、ナビゲーションには丸みのあるフォントを使用し、親しみやすさと楽しさを加えています。

エリア紹介部分では、画像の情報量が多いため背景色を淡くし、各セクションの内容が見やすくなるように調整しました。
また、エリアごとに画像とテキストを左右交互に配置することで、単調にならず、視線が自然に流れる構成を目指しました。

## レスポンシブ対応で意識したこと
スマートフォンでは余白や文字サイズを調整し、情報が詰まりすぎたり、逆に間延びしすぎたりしないようにしました。
また、エリア紹介は縦並びに変更して、狭い画面でも読みやすくなるようにしています。
フッターのナビゲーションは横並びにし、スマートフォンでの視線移動が長くなりすぎないように工夫しました。

## 使用技術
- HTML
- CSS
- Google Fonts

## 工夫した点
-ヒーローに暗幕を入れ、背景画像の上でも文字を読みやすくした
-ナビゲーションにホバーアニメーションをつけ、操作時の楽しさを加えた
-エリア紹介を交互レイアウトにし、視線の流れを作った
-「TOPへ戻る」リンクを設置し、1ページサイトとして使いやすくした
